🔄 Data Flow Example - Simulação de Lucro
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User input (Frontend)
   Ticker: PETR4, Entry: 28.50, Target: 10%
   
   │
   ▼
   
2. API call (frontend/lib/api.ts)
   POST /api/v1/simulations/target-profit
   
   │
   ▼
   
3. Backend receives request (FastAPI)
   Validates with Pydantic schema
   
   │
   ▼
   
4. Service layer calculates
   - Target price: 28.50 * 1.10 = 31.35
   - Stop loss: 28.50 * 0.98 = 27.93
   - Risk/reward: (31.35 - 28.50) / (28.50 - 27.93) = 1.38
   - Probability: based on volatility
   - Scenarios: pessimista, base, otimista
   
   │
   ▼
   
5. Database query (if needed)
   Get historical quotes for volatility calculation
   
   │
   ▼
   
6. Response (JSON)
   {
     "target_price": 31.35,
     "stop_loss": 27.93,
     "risk_reward_ratio": 1.38,
     "probability_target": 48.5,
     "estimated_days": 18,
     "scenarios": {
       "pessimista": {"price": 27.08, "probability": 20},
       "base": {"price": 29.45, "probability": 50},
       "otimista": {"price": 31.35, "probability": 30}
     }
   }
   
   │
   ▼
   
7. Frontend displays results
   Price, Stop Loss, Probability
   3 Scenario bars with percentages


📊 Database Schema
━━━━━━━━━━━━━━━━━

AssetModel
├─ id (PK)
├─ ticker (UNIQUE)
├─ name
├─ asset_type (ENUM: ACAO, ETF, FII, INDICE)
├─ sector
├─ currency
└─ active (BOOLEAN)
   │
   └─ QuoteModel (1:N)
      ├─ id (PK)
      ├─ asset_id (FK)
      ├─ date
      ├─ open
      ├─ high
      ├─ low
      ├─ close
      └─ volume
   
   └─ TechnicalIndicatorModel (1:N)
      ├─ id (PK)
      ├─ asset_id (FK)
      ├─ date
      ├─ rsi14
      ├─ macd
      ├─ bollinger_upper/middle/lower
      └─ volatility_30d

TargetProfitSimulation
├─ id (PK)
├─ user_id (FK)
├─ asset_id (FK)
├─ entry_price
├─ target_gain
├─ target_price
├─ stop_loss
├─ risk_reward_ratio
├─ probability_target
├─ estimated_days
└─ scenarios_json (JSONB)

FixedIncomeModel
├─ id (PK)
├─ codigo_tesoureiro (UNIQUE)
├─ name
├─ tipo (ENUM: ipca, prefixado, selic)
├─ maturity_date
├─ taxa_compra
├─ taxa_venda
├─ pu_bd
├─ pu_pf
└─ vna_atual

UserModel
├─ id (PK)
├─ email (UNIQUE)
├─ password_hash
├─ name
└─ created_at

PortfolioModel
├─ id (PK)
├─ user_id (FK)
├─ asset_id (FK)
├─ quantity
└─ entry_price
